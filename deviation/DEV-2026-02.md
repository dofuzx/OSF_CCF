## **Summary of Deviation**

Species profile data source alignment:Segata Dropbox profiles → Wirbel mOTUs profiles (Zenodo record 3517209)..

## Details of the Deviation

The originally downloaded *`Nine_CRC_cohorts_taxon_profiles.tsv`* (from the Segata laboratory Dropbox) employed native sample identifiers for four cohorts—FengQ_2015, YuJ_2015, YachidaS_2019, and HanniganGD_2017. No publicly available mapping file links these identifiers to the ENA accession numbers used in Wirbel's `meta_all.tsv`, precluding integration of these cohorts (matching was possible only for the Thomas, Vogtmann, Zeller, and Wirbel cohorts).

## **Resolution**

We instead adopted *`species_profiles_g2_l75_motus2.0.0.tsv`* from the same Zenodo record (3517209, the accompanying dataset for Wirbel et al., 2019, Nature Medicine), generated with mOTUs 2.0.0 (7,727 species × 1,641 samples). Its sample identifiers are natively consistent with *`meta_all.tsv`*, yielding 823/825 matched CRC/CTR samples (99.8%); the two unmatched samples corresponded to metadata rows containing NA values. Because this change replaces the quantification method of the original file (which was not documented) with mOTUs 2.0.0 re-quantification, it constitutes a data source alignment rather than a methodological deviation. The KEGG pathway profiles and *`meta_all.tsv`* remain unchanged.
